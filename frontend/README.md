# Frontend — Bet Analyzer AI

Interfaz web (Next.js). **Solo muestra** lo que devuelve la API; **nunca calcula**
el Índice de Apuesta.

Este directorio es un placeholder del scaffolding. Para inicializar el proyecto
Next.js real (cuando toque):

```bash
cd frontend
npm install
npm run dev
```

Responsabilidades:

- Pedir análisis a la API (`POST /analyze`).
- Mostrar índice, probabilidades y explicación tal cual llegan.
- Sin lógica de negocio ni cálculos.
